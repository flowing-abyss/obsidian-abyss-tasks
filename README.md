# Abyss Tasks

A task management interface for Markdown tasks in Obsidian.

The plugin is currently distributed as part of the [Flowing Abyss vault](https://flowing-abyss.com/Description-of-Obsidian-Vault).
Documentation and a wider public release will follow after the initial testing period.

Existing task, project, note, tag, property and icon searches forgive small typos. In an active Tasks,
Search or Projects overview, press Cmd/Ctrl+F to select its search input. Escape returns focus to the
surface while keeping the search. Searchable pickers also support Cmd/Ctrl+F and keep their usual
Escape behavior.
